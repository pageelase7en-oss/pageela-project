# KOLBE SPORT PROJECT V6 — Core Engine

این نسخه یک مرحله‌ی بزرگ‌تر از V5 است: بخش‌های اصلی پروژه از حالت نمایشی خارج شده‌اند و به Supabase متصل شده‌اند.

## امکانات این نسخه

- احراز هویت Supabase قبلی
- پروفایل واقعی کاربر با موجودی اولیه صفر
- امتیازهای تسک در دیتابیس
- ثبت امن تسک با RPC و جلوگیری از ثبت دوباره
- کد معرف واقعی برای هر حساب
- کد هدیه با محدودیت مصرف و جلوگیری از استفاده دوباره
- پیش‌فروش PAGEELA با درصد رزرو واقعی در دیتابیس
- به‌روزرسانی زنده پیش‌فروش از طریق Realtime
- ثبت سفارش از سبد خرید در Supabase
- کیف پول به‌صورت Ledger فقط خواندنی برای کاربر
- بازار کاربران با خواندن آگهی‌های واقعی
- ساخت آگهی فقط برای مالکیت‌های واجد شرایط
- مرکز مدیریت برای مدیر پروژه
- مدیریت محصول، تسک، کد هدیه و پیش‌فروش توسط مدیر
- RLS برای جداول حساس
- توابع سمت دیتابیس برای عملیات حساس
- تصاویر مرجع V5 حفظ شده‌اند

## راه‌اندازی

1. Node.js 20+ نصب باشد.
2. `npm install`
3. `.env.example` را به `.env.local` کپی کن.
4. مقدار `NEXT_PUBLIC_SUPABASE_URL` را از Supabase > Project Settings > API بردار.
5. کلید publishable را در `.env.local` قرار بده.
6. در Supabase SQL Editor، `supabase/schema.sql` را کامل اجرا کن.
7. سپس `supabase/seed.sql` را کامل اجرا کن.
8. `npm run dev`

## فعال‌کردن ادمین

بعد از ساخت حساب خودت، داخل SQL Editor ایمیل خودت را جایگزین کن و اجرا کن:

```sql
update public.profiles
set role='admin'
where id=(select id from auth.users where email='YOUR_EMAIL');
```

سپس `/admin` را باز کن.

## نکته مهم درباره پول

این نسخه هنوز درگاه پرداخت واقعی ندارد. پیش‌فروش، سفارش و Ledger ساختار واقعی دیتابیس دارند، اما هیچ‌کدام نباید به‌عنوان پرداخت قطعی تلقی شوند تا در مرحله‌ی مالی، درگاه و منطق تسویه امن سمت سرور اضافه شود.

هرگز `service_role` یا secret key را داخل `NEXT_PUBLIC_*` قرار نده.
